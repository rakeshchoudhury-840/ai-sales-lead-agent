# Project Requirements Mapping

This project intentionally demonstrates:

- Python
- FastAPI
- FastMCP
- LLM / agent
- Tool calling
- Structured output with Pydantic
- RAG-style knowledge retrieval
- Multi-turn session history
- Deterministic lead qualification
- Sales workflow
- Follow-up generation
- Automated tests/evaluation
- GitHub-ready documentation

Not included yet: WhatsApp Business API, voice/Ringg, real CRM integration, real email sending, authentication, production deployment, observability, and a persistent conversation store. Add these before claiming them on a resume.
